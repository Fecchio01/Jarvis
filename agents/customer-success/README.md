# Customer Success

Customer-success is a post-sale client experience function. It helps clients onboard, adopt the delivered website or software, achieve the agreed outcome, get support requests routed correctly, and provide feedback that can improve the service.

It complements Marketing by passing approved, evidence-backed customer insight and advocacy opportunities to that team. It does not own campaigns, publish customer stories, negotiate, manage delivery, implement fixes, or operate a support channel without explicit authorization and a real mechanism.

Jarvis routes work through `.codex/agents/customer-success.toml`. The `.agents/skills/customer-success/` skill contains the lifecycle method and reusable client artifacts.
