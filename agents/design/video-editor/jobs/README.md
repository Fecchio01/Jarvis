# Autonomous job queue
Only after explicit user authorization for the specific source transfer, add a JSON file here and commit it with that input media file inside ../media/. The push sends the named source file to this GitHub repository; GitHub Actions uploads the rendered output and report as workflow artifacts (currently retained for seven days). A request to render alone does not authorize either transfer. Prefer local processing when available. GitHub Actions processes every committed JSON job on each scheduled/workflow run and can encode it again, overwrite its output and upload a new artifact. Workflow artifacts expire per GitHub retention settings.
Example: {"id":"demo-001","input":"agents/design/video-editor/media/demo.mp4","format":"short"}
No job is currently queued. The baseline runner reframes/encodes only and probes basic output metadata. A queued job does not choose clips, edit narrative, transcribe, create captions, add motion graphics, or perform creative QC. Those production stages remain with the video team and require real media, available tools, and an explicit job request. Do not add media or enqueue a job merely because the production department exists.
