# Video repurposing (Jarvis-maintained)
1. Transcribe when tooling exists and verify critical words against audio.
2. Identify self-contained insights and source in/out timestamps; avoid misleading excerpts.
3. Make a clip selection table with hook, audience value, duration and supporting B-roll.
4. Reframe for 9:16 with face/product safe zones, preserve intelligibility.
5. Caption accurately; avoid excessive word-by-word animation when it hurts readability.
6. Export platform-ready versions and cover; provide original source timestamps.
7. Never use unlicensed footage/music.
